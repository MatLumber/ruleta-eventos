# Ruleta de Eventos

Ruleta para sorteos en vivo, para Windows 10 y 11 (64 bits). Un solo archivo: no se instala nada y funciona sin internet.

## Descargar

**[Descargar la última versión](https://github.com/MatLumber/ruleta-eventos/releases/latest/download/Ruleta.de.Eventos.exe)**

1. Descarga el archivo y ábrelo con doble clic.
2. Si Windows muestra «Windows protegió su PC», elige **Más información** y luego **Ejecutar de todas formas** (pasa porque el programa no tiene firma digital de pago).

## Actualizaciones

El programa revisa solo si hay una versión nueva cada vez que se abre y la descarga en segundo plano. Cuando está lista aparece el botón **«Actualizar a …»** en la barra de arriba: se instala solo cuando el operador lo pide, nunca en medio de un sorteo.

## Dónde quedan los datos

Las ruletas, listas y ganadores se guardan en `%APPDATA%\RuletaDeEventos`, así que no se pierden al actualizar o mover el programa. Para llevar todo en un pendrive, crea un archivo `portatil.txt` junto al `.exe`: los datos se guardarán al lado del programa.
